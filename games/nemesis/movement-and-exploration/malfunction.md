# Malfunction Markers

Category: Movement and Exploration - Malfunction
Related Systems: Engines, Rooms, End of Game, Item Decks

## Effects on Room Actions [[R1-MALFUNCTION]]

If a Malfunction marker is present in a Room, that **Room's Action is no longer available**. This applies even to Special Rooms like the Hibernatorium, Cockpit, or Engines.

**Important Engine Exception**: You can still Repair/Break an Engine even if the Engine Room has a Malfunction marker, since the disabled room action is "Check Engine Status" not the repair function [[R1-MALFUNCTION]].

## Effects on Other Room Features

- **Search Actions [[R1-MALFUNCTION]]**: Malfunction markers do **not** prevent Search Actions from being performed in that Room.
- **Computers [[R1-MALFUNCTION]]**: If a Room has a Computer icon but contains a Malfunction marker, the Computer becomes unavailable, as if there were no Computer icon present.

## Ship Hull Integrity (Game End) [[R1-MALFUNCTION]]

There are 8 Malfunction markers in game. If you are instructed to place a **9th Malfunction marker** and none are available from the pool, the ship immediately loses hull integrity and explodes, killing all Characters (awake or hibernated) and Intruders on board.

## How Malfunction Markers Are Placed [[R1-MALFUNCTION]]

- **Exploration tokens**: "Malfunction" exploration tokens place markers when rooms are first entered
- **Event cards**: Certain events can place Malfunction markers. For example, the **Malfunction** event card places a Malfunction marker in the explored Room with the lowest Room Number [[EVT1]].
- **Other game effects**: Various Actions may also cause malfunctions. For example, the **Demolition** Action card can be used to place a Malfunction marker in a room.

## Removal of Malfunction Markers

- **Repair Action cards**: Various Action cards can discard Malfunction markers
- **Tools Item card**: Found in Technical Items (Yellow Deck) [[ITM1-YELLOW]], allows "Discard Malfunction"
- **Duct Tape**: Also in Technical Items (Yellow Deck) [[ITM1-YELLOW]], can "Discard Malfunction"

## Specific Rules

- A Room can **never hold more than one Malfunction marker** at a time. If you are instructed to place another one, nothing happens [[R1-MALFUNCTION]]
- Discarded Malfunction markers are returned to the pool for future use [[R1-MALFUNCTION]]
- Malfunction markers **cannot be placed** in the Nest or Room Covered In Slime [[R1-MALFUNCTION]]
